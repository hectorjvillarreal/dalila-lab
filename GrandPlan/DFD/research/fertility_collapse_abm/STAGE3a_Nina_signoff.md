# Stage 3a — Nina's Gate

## Verdict — endorsed

The no-reflexivity ABM (κ(b) cohort decline + φ(b) formation tilt + π(t) exogenous period
shifter) reproduces CR and COL composition collapse on pre-registered gates (M1 0.975/1.044;
M2 |Δ| ≤ 0.04), beating the rejected threshold skeleton on N1 loss. **Sufficiency established
on magnitude and late-loading**, with one unreproduced shape residual (COL M3) routed to ENDS.

**The endorsement does not rest on magnitude capture** — three added mechanisms make that table
stakes. It rests on three convergences with 2b the model was *not* fit to: (a) κ(b) inflects at
birth cohorts ~1988–90 = the 2b APC crossover (non-fit); (b) the ablation reproduces the 2b
decomposition (COL cohort essential +63%; period dispensable); (c) no-reflexivity beats the
threshold skeleton. That is mechanism validation, not curve-fitting.

## Five binding conditions (carry into the memo before it feeds Fina M2/M4)

1. **Lead with the non-fit convergence; report κ(b)'s functional form and parameter count.**
   The credibility is the 1988–90 inflection recovery, and it is only strong if κ(b) is
   parsimonious. A low-parameter logistic in birth cohort → strong. A flexible per-cohort effect →
   the inflection is fitted and the convergence is circular. This determines whether sufficiency
   is real. Magnitude capture is table stakes, stated as such.

2. **κ–φ separability.** Both act on the marriage-entry margin. Report which data moments pin
   each; if they are not separately identified, the "cohort gradient" hides degrees-of-freedom
   inflation. Show they trade off against different moments, or collapse to one term.

3. **Period reconciliation + cohort-only headline.** The "period dispensable" ablation and 2b's
   "COL period significant" are the same finding (significant but small; curvature 0.007;
   cohort-dominant) — state it. Since period carries ~nothing in either country, make the
   **cohort-only model the headline specification**; period shifter is documented
   secondary/robustness. Tighter story, smaller overfitting surface, better match to the 2b
   decomposition.

4. **COL M3 kink — precise framing, kept prominent.** A shape residual (2019–22 Δ²-sign),
   provisionally pandemic-era GEIH collection or a discrete exogenous shock, ENDS-resolvable. It
   does **not** reopen (B) — a kink a smooth model misses is not cascade evidence; only ENDS
   transitions can touch (B). Headline reads "sufficiency on magnitude and late-loading, one
   unreproduced shape residual," not an unqualified "established."

5. **No-reflexivity — the load-bearing verification.** The endorsement stands entirely on κ, φ, π
   depending only on (birth cohort, calendar time), never on contemporaneous cross-agent
   composition (`agent_step!` no cross-agent read; wall log static + runtime). Confirmed as
   reported; **void if that code-read is not exactly true.**
