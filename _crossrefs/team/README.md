# _crossrefs/team — per-member briefing folders

One folder per Core Team member (and, where relevant, human coauthors such as
Judy). Each holds the briefings addressed to that person, copied here from the
mission or project folder where they were produced.

Convention (established 2026-08-08, first population: BID2 motivation build):

- **Canonical copy lives with the work** — in the mission/project folder that
  produced it (e.g., `Missions/Funded/BID2/motivation/`), alongside the
  scripts and outputs it describes. The copy here is the recipient-facing
  view; if the two ever diverge, the mission copy wins.
- Filenames keep the origin convention:
  `YYYYMMDD_<MISSION>_briefing_<name>_<topic>.md`.
- A folder is created when its member first receives a briefing; empty
  folders are not pre-created.
